# Math Library (Legacy — 2018)

A JavaScript library for solving complex problems in **Analytical Geometry**, Statistics, Algebra, and Combinatorics.

## 📌 Context & Purpose
This is a **pre-junior level project** written in 2018. 
I developed this tool to automate my academic workload, including coursework and complex analytical calculations. 

**The core value:** The library didn't just provide a final result; it was designed to generate a **step-by-step solution process**, allowing me to automate the tedious manual work of solving academic assignments.

### Key Features (as of 2018):
* **Analytical Geometry:** Working with triangles and shapes in a coordinate system (finding equations of lines, intersections, distances between points, and angles).
* **Statistics:** Variational series, distribution characteristics, and statistical models.
* **Probability Theory:** Implementation of Bernoulli trials and Laplace theorems.
* **Combinatorics:** Complex calculations involving factorials, combinations ($C_n^k$), and permutations.

### Technical Context:
* **Language:** Vanilla JavaScript (**ES5**).
* **Architecture:** Prototype-based inheritance.
* **Localization:** Ukrainian.
